# MindAttic.Helpers — how to work here

Small, zero-dependency .NET (`net10.0`) library of pure, deterministic helpers shared
across MindAttic. Two projects: `MindAttic.Helpers` (the library, packable) and
`MindAttic.Helpers.Tests` (NUnit). Solution: `MindAttic.Helpers.slnx`.

## Build & test
```bash
dotnet build                 # build library + tests
dotnet test                  # run the NUnit suite (16 tests at last check)
```

## Codex — canonical documentation (read this first)
This repo uses the MindAttic **Codex** standard. The docs are the source of truth for
what the project IS and the rules that keep it coherent:

- **`docs/BIBLE.md`** (L0) — source of truth: the one sentence, what it is/isn't,
  architecture canon, the Laws, verified state, glossary.
- **`docs/AMENDMENTS.md`** (L1) — append-only change log; **an amendment wins over the
  bible** where they disagree.
- **`docs/USER_STORIES.md`** (L2) — test-cited stories; every ✅ names its verifying test.
- **`docs/rfc/`** — design notes that graduate into the bible + stories.
- **`docs/BIBLE.digest.md`** — GENERATED by `tools/codex.ps1`; never hand-edit. Injected
  at session start via `.claude/hooks/inject-digest.ps1`.
- **`MindAttic.HouseRules.md`** (repo parent dir) — org-wide laws the bible §5 inherits.

### Rules for editing canon
- **Single home per fact.** A fact lives in exactly one layer; everything else links to
  it by stable ID (`{#M.HELP-§N}`, `{#M.HELP-LAW-n}`, `M.HELP-US-<Epic><n>`, `HLP-A<n>`). Never
  reference line numbers.
- **Done means verified.** Mark a story ✅ only when a named test or the build proves it;
  otherwise 🟡/⬜ (see [HOUSE-LAW-8](MindAttic.HouseRules.md#HOUSE-LAW-8)).
- **Append-only L1.** Never rewrite an amendment; supersede it with a new one.
- **Don't hand-edit the digest.** Run `tools/codex.ps1 digest` to regenerate it.

### Tooling
```powershell
powershell -File tools/codex.ps1 digest   # regenerate docs/BIBLE.digest.md
powershell -File tools/codex.ps1 doctor   # validate front-matter, IDs, refs, stories, digest
```
Run `doctor` before committing doc changes; it must exit clean.

## Project laws (full set in docs/BIBLE.md §5 + MindAttic.HouseRules.md)
- **Zero runtime dependencies** — the library references only the .NET BCL ([M.HELP-LAW-1](docs/BIBLE.md#M.HELP-LAW-1)).
- **Helpers are pure, deterministic, static** ([M.HELP-LAW-2](docs/BIBLE.md#M.HELP-LAW-2)).
- **Faithful ports stay bit-for-bit** ([M.HELP-LAW-3](docs/BIBLE.md#M.HELP-LAW-3)).
- **Every helper is locked by tests** ([M.HELP-LAW-4](docs/BIBLE.md#M.HELP-LAW-4)).
- **Whole-number versioning** — `1.0.0` → `2.0.0` → … ([HOUSE-LAW-1](MindAttic.HouseRules.md#HOUSE-LAW-1)).
